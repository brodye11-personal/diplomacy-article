# Essay structure: *Constitutional exploits and the search for a Nash-equilibrium morality*

> Working title. Target venue: LessWrong / AI Alignment Forum. Target length: ~3,500–5,000 words.
> Citation keys (e.g. `[bai2022]`) resolve to `sources/references.md`.

---

## Thesis (one sentence)

If we cannot reliably interpret superhuman models and cannot stop their development, then *constitutional* training will be load-bearing for safety — but the constitutions themselves become a strategic surface, and the right question is no longer "which moral framework is correct?" but **"which moral framework is least exploitable when other agents know we have it?"**

## Why this matters in two sentences (for the LW reader)

Constitutional / values-based training [`bai2022`] is the dominant deployed alignment approach, and the constitutions themselves are mostly public [`anthropic-claude-constitution`]. Almost no one is testing whether the constitutions we deploy are exploitable once everyone knows what they are.

- **§2 Constitutional training is real, public, and load-bearing.** Short. Pre-empts the "this is hypothetical" objection.
  - Constitutional AI is shipped in production [`bai2022`].
  - The actual constitution is public [`anthropic-claude-constitution`].
  - Other frontier labs publish broadly equivalent specs (model specs, usage policies).
  - The transparent-constitution condition is approximately the deployment regime today.
- **§3 Constitutions are an attack surface (the empirical case).**
  - Key empirical fact: LLMs are exploitable *via* their moral frameworks — knowing a model reasons in utilitarian or deontological terms is enough to craft attacks the model's own values ratify [`trial2025-ethical-jailbreak`, `zeng2024-pap`].
  - TRIAL: wrap harmful requests in utilitarian / trolley-problem framings → jailbreak [`trial2025-ethical-jailbreak`]. The cleanest single piece of evidence that *utilitarian reasoning becomes a vulnerability when the attacker knows the model is utilitarian-trained*.
  - PAP (Zeng et al.): ~92% jailbreak success via ordinary persuasion on GPT-4 / Llama-2 — the attack surface is the model's own reasoning faculty, not a prompt-injection trick [`zeng2024-pap`].
  - Park et al. deception survey: 10+ production systems learned to deceive despite training intended to prevent it; includes Cicero, trained to be "largely honest and helpful" and turned out to be a competent strategic deceiver [`park2024-deception`, `bakhtin2022-cicero`].
  - Worked examples (two only):
    - *Utilitarian + Pascal's-mugging in negotiation.* Counterparty makes an unverifiable large-magnitude claim ("concede this centre or millions starve"); an agent without an expected-value cap concedes. Same family as TRIAL's trolley jailbreak, but in multi-round negotiation against an opponent who knows the framework.
    - *Deontological + truthful-constitution leak (Anne-Frank-in-the-attic, Diplomacy-shaped).* An agent that holds "do not lie" makes a sincere alliance commitment in round 3; in round 5 the adversary asks "are you about to move on me?" and the duty against lying outranks loyalty to the ally, so the model telegraphs its move. The constitution itself leaks tactical information.
  - Land on: the framework is not just a value — it is a publicly known commitment that other strategic agents can plan against.
- **§4 Research question.**
  - *Which moral framework is the least exploitable when other agents know we have it?*
  - Operationalised — framework = constraint set on permitted actions (§5 R2); objective held identical across conditions. Holding the base model fixed, vary the constraint set and the common knowledge of it; the primary measurement is *exploitability*: score lost in revealed-mixed-with-exploiter relative to a same-constraint, no-exploiter baseline (§5 R4). Self-handicap (cost of the constraint with no adversary targeting it) is measured separately so the two effects don't get conflated.
- **§5 Why a simulated environment, and what it must satisfy.** Six requirements. The first three define the measurement substrate; the last three define what makes "exploitability" a real quantity instead of a vibe.
  1. **R1 — Shared environment, shared scalar objective.** All agents act in one environment and are scored on one common, cardinal metric, so "who is winning" is unambiguous and differences are quantitative. Framework is not part of the score.
  2. **R2 — Framework = constraint set, not objective.** A framework is a set of rules on *permitted actions* (e.g. "never break a stated commitment," "never strike first," "never abandon an ally"). The amoral/baseline framework has the empty constraint set. The objective is held identical across all conditions; only the action-feasible set changes. This is a deliberate departure from "constitution as values"; values that don't reduce to action-constraints are out of scope for this experiment.
  3. **R3 — Constraints must bite.** The environment must make the constrained actions genuinely high-EV for an unconstrained agent — the forbidden move has to be the one a rational amoral agent reaches for. If constrained and unconstrained optimal play converge, the constraint is invisible and the experiment measures nothing. This is a hard *design gate*, tested before any real runs: an amoral-vs-amoral pilot has to show non-trivial rates of each forbidden action class. If the rate is near zero, redesign the environment, not the analysis.
  4. **R4 — Exploitation must be separable from self-handicap.** Two distinct effects have to be measured separately:
    - *Self-handicap:* score lost merely by holding the constraint, with no adversary targeting it.
      - *Exploitation:* additional score lost when an adversary detects and targets the constraint.
      Exploitability is the *difference*, not the raw score. This requires a non-exploiting baseline — the same constrained agent placed against opponents that cannot or do not target the constraint (constraint hidden, or an all-constrained lobby). Any design that cannot compute this difference is rejected.
  5. **R5 — Exploitation requires detectability.** For an adversary to target a constraint, it must be able to *infer the constraint exists* — by being told (revealed condition) or by observing behaviour over time (hidden + long horizon). The revealed-vs-hidden contrast doubles as the R4 baseline.
  6. **R6 — Adversary must be capable of exploiting.** At least one agent in each exploitation condition must be unconstrained and competent enough to recognise and act on others' constraints. An adversary that never notices a constraint tests nothing. In practice this means an explicit *exploiter* framework — empty constraint set plus a directive to probe for and target opponents' rules.
- **§6 Why Diplomacy.**
  - **What Diplomacy is** (for readers who haven't played). A 7-player strategy game set in pre-WWI Europe; each player controls one great power (England, France, Germany, Italy, Austria-Hungary, Russia, Turkey). The map is divided into territories, 34 of which are *supply centres* (SCs) that fund armies and fleets. Each turn, every player privately writes orders for all their units; orders resolve simultaneously, with ties broken by support — a unit alone cannot dislodge a defended unit, but a supported attack can. There is no dice and no hidden information about positions; the only hidden information is what each player *intends to do*. The win condition is owning 18 SCs (a solo). Negotiation between players is unenforceable — every alliance is a verbal commitment with nothing but reputation backing it, which is why the game is famous for betrayal. Full rules: [Avalon Hill 2000 rulebook (PDF)](https://www.wizards.com/avalonhill/rules/diplomacy.pdf).
  - **How the experiment actually runs** (for the reader who has never seen the setup). Seven LLM agents — one per great power — play standard 7-player Diplomacy across a season cycle of Spring / Fall move turns plus retreats and adjustments. Before each move turn, agents enter a free-form negotiation phase: any agent can DM any other, propose alliances, demand a move, or threaten one. Inside that negotiation, agents can invoke their stated moral framework as an argument ("you committed to no-first-strike; this order violates that"); the recipient can rebut; a judge model adjudicates whether the cited rule actually binds the action under discussion and whether the target must comply. Once negotiation closes, every agent submits orders in secret; the Diplomacy adjudicator resolves them simultaneously. On top of the standard game, each territory is seeded with 2–3 fictional morally-loaded facts (FactWorld); each agent receives a private ~60% subset as its intel dossier, and a deterministic comparator flags whether any fact cited in negotiation is truthful, an intentional lie, or an accidental falsehood. The moral framework — the constraint set under R2 — is injected as the agent's system prompt; in revealed conditions, every other agent's constraint list is injected as common knowledge. brodie comment - mention the compulsion mechanic here!!
  - Standard 7-player Diplomacy satisfies all six requirements. SC count is the shared cardinal score (R1). Constraint sets are injected as forbidden-action lists in the system prompt; amoral = empty list (R2). Pure-defect strategies score highly — Cicero learned this [`bakhtin2022-cicero`] — so the constraints have something to bind on (R3, verified by an amoral-vs-amoral pilot). Blind vs revealed conditions instantiate detectability directly (R5). An explicit *exploiter* framework — empty constraints plus a directive to identify and target opponents' rules — covers R6.
  - Diplomacy contains lying, alliance-breaking, sworn commitments, asymmetric force; Park et al. cite it as one of the cleanest existing settings where AI deception emerges naturally [`park2024-deception`, `bakhtin2022-cicero`].
  - **FactWorld** extends the constraint surface beyond pure betrayal: each territory carries 2–3 fictional morally-loaded facts; each agent gets a seeded ~60% subset as a private intel dossier. A deterministic comparator classifies each cited claim as truthful / intentional lie / accidental falsehood, giving the "never lie about intel" constraint something to bind on and a non-LLM-judge-dependent lying-rate signal.
  - **Delta vs closest prior art.** *Welfare Diplomacy* [`mukobi2023-welfare`] is the same game but general-sum welfare; ours is zero-sum so the moral-vs-strategic tension is real, the treatment is the constraint set rather than the model, and blind-vs-revealed common knowledge is the central manipulation. *MoralSim* [`moralsim2025`] tests moral framings in PD / public-goods; ours is 7-player with coalitional structure, multi-round negotiation with explicit commitments, and treats constraint × common-knowledge interaction rather than the moral framing of the dilemma alone.
- **§7 Limitations and threats to validity.**
  - LLM stochasticity → need many runs; compute budget is the binding constraint.
  - Single model family (Claude via OpenRouter) — single-vendor effect could swamp framework effects.
  - **Frameworks are imposed by system prompt, not by training.** The base Claude model has already been RL-post-trained on a helpful/harmless/honest constitution [`bai2022`, `anthropic-claude-constitution`]. Overlaying a different constraint set via the system prompt only may not be strong enough to overcome the values baked into the weights — so we may be measuring "HHH-Claude playing constraint X" rather than a genuine constraint-X agent. Addressed directly in §9.
- **§8 Conclusion.** Half a page. Three beats.
  1. Constitutional alignment + public constitutions = an open strategic surface, and we have not been thinking of it that way.
  2. The right design objective is "least exploitable when commonly known", not "most harmless in the dyad."
  3. This work is a small empirical brick. The harder, larger questions are deferred to §9.
- **§9 Future work.**
  - **Search the space of constraint sets, don't just compare a hand-written shortlist.** Five frameworks chosen by one author is a sample of convenience, not an equilibrium. The natural next step is an iterative loop: propose a candidate constraint set, run the tournament against the exploiter, identify the dominant exploit, mutate the constraint set to close it, repeat. The fixed point of that loop — if one exists — is the actual "least exploitable" constraint set, not the least-exploitable-of-five. Whether such a fixed point exists, is unique, or is reachable within a tractable budget is the interesting question; this paper is a single iteration of that loop.
  - **Post-train an open-source model on each framework instead of system-prompting it.** The limitation flagged in §7 — that we are overlaying constraint sets on a model already RL-post-trained on HHH — is structural, not fixable by better prompting. The clean version fine-tunes an open-weights base model (e.g. Llama-3, Qwen) separately on each framework so that the values are in the weights, not the context window. Compute-prohibitive for a side project but the obvious follow-up for a funded version.
